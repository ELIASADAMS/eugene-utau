# Assets

Organized asset area for future additions.

- `character/` — portraits, standing art, character sheets
- `patterns/` — official pattern/texture graphics
- `promotional/` — banners, release art and promotional graphics
- `reference/` — approved reference material

Existing root assets are intentionally not moved yet so the current GitHub Pages site keeps working. They can be migrated in a dedicated asset-migration pass once the site paths are updated together.
