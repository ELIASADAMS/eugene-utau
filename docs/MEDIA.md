# Eugene Media Archive

This file records finished works that demonstrate or feature 友人 (Eugene). It is an archival index; the individual works remain on their original platforms.

## Official / Eugene-centered works

### しあわせがこわい

**English:** I'm Afraid of Happiness  
**Artist:** Ilya Minin (Eli)  
**Voice:** 友人 (Eugene)  
**YouTube:** https://youtu.be/K9z59T5WcG0

Released June 2026 alongside the Eugene voicebank. The public release text describes Eugene as Eli's fourth UTAUloid and emphasizes a voice assembled from preserved fragments, reconstructed phonemes and memory. The work is the primary listening reference for the released bank.

## Works featuring Eugene with other voicebanks

### Gonshan

**Based on:** poetry by Japanese author Kitahara Hakushū  
**Voices:** タキスマナ (Takismana) + 友人 (Eugene)  
**YouTube:** https://youtu.be/0SrTzStv-j4

The public release credit describes significant help from Ilya Minin (Eli) with visual materials, sophisticated tuning and mastering. This is an important example of Eugene functioning as part of a multi-voicebank work rather than only as a solo voice.

## Other discovered references

### Sea Shanty — Wellerman (Japanese)

A Japanese custom-voicebank cover using **タキスマナ (Takismana)** and **茜音イーライ (Akane Iirai)**.  
**YouTube:** https://youtu.be/eGvrAAnUAbI

This work is relevant to the broader ELI LAB voicebank ecosystem and demonstrates the updated Iirai bank in a shared vocal arrangement.
