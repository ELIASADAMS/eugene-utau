USAGE GUIDE

Using 友人in your work

A concise practical guide for working with the released Japanese CVVC bank in UTAU and OpenUtau.

01

Compatibility

Japanese CVVC · Romaji · UTAU / OpenUtau

The bank is encoded in Romaji and uses CVVC aliases. A Japanese CVVC-compatible workflow is recommended.

02

Basic workflow

  1. Install the released 友人 voicebank.
  2. Use a Japanese CVVC-compatible workflow in UTAU or OpenUtau.
  3. Start with TIPS and moderate expression settings.
  4. Test sustained vowels and consonant transitions before building a full arrangement.
  5. Compare resamplers when a different texture or response is desired.
